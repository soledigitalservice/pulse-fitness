# Pulse Fitness Club — Demo

Sitio web demo para un **gimnasio**, diseñado por [Sole Digital Service](https://soledigitalservice.com).

Página única, responsive y autocontenida (un solo `index.html`, sin dependencias). Incluye:
- Hero con métricas y "primera clase gratis"
- Clases, planes de membresía y horario
- Botón flotante de WhatsApp

## Ver en local
Abre `index.html` en el navegador, o sírvelo:
```bash
npx serve .
```

## Publicar gratis (GitHub Pages)
Sube este repo a GitHub y activa **Settings → Pages → Deploy from branch → main / root**.

_Proyecto de demostración. Datos y marca ficticios._
